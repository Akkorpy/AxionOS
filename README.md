## AxionOS
An experimental WebOS project focused on creating a basic desktop interface inside the browser.

<img width="1607" height="909" alt="image" src="https://github.com/user-attachments/assets/3e16c2e3-a14e-46bf-9bcb-22a8e7eaa8ed" />

## Features
- Draggable, closable windows
- About Me, Contacts, Cosmic Journal and Weather (on development) apps
- Live clock and date in the top bar
- Dock with app icons

## Tech
HTML, CSS, vanilla JavaScript, Formspree service. Hosted on GitHub Pages.

## How to run
Open `index.html` in a browser
